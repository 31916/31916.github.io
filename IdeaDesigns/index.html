Number Cursors 4

ZIP↓
Windows
  1. Unblock the ZIP in Properties, then extract it.
  2. Open the Windows folder in a terminal and run:
    powershell -ep RemoteSigned -f Register-Scheme.ps1

  3. In main.cpl → Pointers, apply Number Cursors v4 (#CCCCCC).
macOS
  1. Open the latest Mousecape-swiftUI release. Under Assets, download Mousecape_swiftUI_*.zip, extract it, and move Mousecape.app to Applications (macOS 15 or later).
  2. Extract the ZIP and import macOS/Number_Cursors_4.cape in Mousecape.
  3. Select Number Cursors 4 and click Apply.
Linux
  1. Extract the complete ZIP. Open its Linux folder in a terminal and run sh install.sh. Run it again to install an update.
  2. The installer applies the theme in GNOME. In KDE Plasma, open System Settings → Cursors and apply Number Cursors 4.
  3. Fully quit and reopen applications to reload the theme. After an OS upgrade, log out and back in to restart the desktop.
  4. If GNOME Settings still uses the standard cursor in an older Wayland session, fully close Settings and run GDK_BACKEND=x11 gnome-control-center. See Linux/README.txt for details.
