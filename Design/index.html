Number Cursors 4

ZIP↓
▼
Windows
  1. Unblock the ZIP in Properties, then extract it.
  2. Open the Windows folder in a terminal and run:
    powershell -ep RemoteSigned -f Register-Scheme.ps1

  3. In main.cpl → Pointers, apply Number Cursors v4 (#CCCCCC).
macOS
  1. Install Mousecape-swiftUI (macOS 15 or later).
  2. Extract the ZIP and import macOS/Number_Cursors_4.cape in Mousecape.
  3. Select Number Cursors 4 and click Apply.
Linux
  1. Extract the ZIP. Copy Linux/Number_Cursors_4 into ~/.local/share/icons/. Create the icons folder if needed.
  2. In KDE Plasma, open System Settings → Cursors and apply Number Cursors 4. In GNOME, run gsettings set org.gnome.desktop.interface cursor-theme 'Number_Cursors_4'.
