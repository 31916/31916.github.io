Number Cursors

A Windows cursor set built from numerals. A tilted 4 points, and a spinning 6 turns into a 9 while Windows is busy.

  • 17 cursors
  • 32, 48, 64 px
  • #CCCCCC
Download ZIP ↓

v1.0.0 · 383 KiB · 2026-11-05 · SHA-256

Set up in Windows
  1. Extract the ZIP.
  2. Press Win + R, open main.cpl, and select the Pointers tab.
  3. Select a pointer role, choose Browse, and pick its matching file from the cursors folder. The Japanese README.txt lists the roles and files.

To register the full scheme, open PowerShell in the extracted folder and run these commands.

Unblock-File -LiteralPath .\Register-Scheme.ps1
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Register-Scheme.ps1

On the Pointers tab, choose Number Cursors (#CCCCCC) under Scheme and select Apply.
