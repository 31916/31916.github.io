Original thumbnail layout, typography and process arrows by 31916.
Five real Google product logos are embedded as SVG paths. Logos retain their
source shapes and colors; only layout and scale are changed. No application
screenshot is imitated or generated. The 2020 logo set matches the existing
Sheets, Docs and Gmail materials; it is not described as the latest logo set.
Google retains its relevant trademark rights. This is an independent tutorial.
